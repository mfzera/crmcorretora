# 🎥 Roteiro do Vídeo (até 2 minutos)

Fala pessoal, tudo certo?

Pra quem não me conhece, eu sou o Miguel, faço parte da comunidade Rocketseat, e hoje eu quero compartilhar algo que mudou muito meu nível como dev:

**Entender Git de verdade.**

Muita gente usa Git só no básico:

`git add`  
`git commit`  
`git push`

Mas sem entender o que realmente está acontecendo.

E pra mim, a virada de chave foi entender três coisas simples 👇

---

## 1️⃣ Branch é contexto, não bagunça

Branch não é só uma cópia do projeto.

É um **espaço seguro** pra você criar uma feature sem quebrar o que já está funcionando.

Por exemplo:

`main` → código estável  
`feature/login` → você desenvolve isolado

Depois você junta tudo com um merge ou pull request.

Isso muda completamente a forma como você trabalha em equipe.

---

## 2️⃣ Commit não é só salvar — é comunicar

Commit bom explica **o porquê**, não só o que foi feito.

Ao invés de:

> ajustes

Melhor:

> refactor: melhora validação do formulário de cadastro

Isso ajuda você do futuro…  
E ajuda muito o time também.

---

## 3️⃣ Controle de versão é confiança

Quando você entende Git, você perde o medo de testar.

Você sabe que pode errar.  
Você sabe que pode voltar atrás.

E isso aumenta muito sua velocidade como dev.
