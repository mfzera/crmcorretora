## DIRETRIZES DE EXECUÇÃO

| Item | Regra |
|------|-------|
| Fundo | Sempre preto `#000000` ou `#0a0a0b` nos cards |
| Destaque | Azul `#2563EB` para números, CTAs, labels |
| Tipografia | Inter para textos, Geist Mono para labels técnicas |
| Labels | Estilo `SÉRIE_01 / POST_NOME` em mono uppercase |
| Tom | Direto, técnico, sem buzzwords. Nunca "solução inovadora" ou "revolucionário" |
| Logo | Sempre versão branca sobre fundo escuro nos posts dark |
| Grid | Usar a textura de pontos azuis como fundo em pelo menos 1 post por semana |
