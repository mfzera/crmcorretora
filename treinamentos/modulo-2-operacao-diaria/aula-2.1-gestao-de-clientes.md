# Aula 2.1 — Gestão de Clientes

## Objetivo
Aprender a cadastrar, buscar e gerenciar clientes, bem como vincular documentos e consultar histórico de apólices.

---

## Como cadastrar um novo cliente

1. No menu lateral, clique em **Clientes**
2. Clique no botão **"Novo Cliente"**
3. Preencha os dados obrigatórios:
   - Nome / Razão Social
   - CPF ou CNPJ
   - E-mail
   - Telefone
4. Preencha os dados complementares (endereço, data de nascimento etc.) conforme necessário
5. Clique em **Salvar**

> Campos marcados com `*` são obrigatórios.

---

## Como buscar um cliente existente

1. Acesse **Clientes** no menu lateral
2. Use a barra de busca no topo da lista
3. Você pode buscar por: nome, CPF/CNPJ ou e-mail
4. Clique no cliente para abrir o cadastro completo

---

## O que você encontra no cadastro de um cliente

- **Dados pessoais** — Nome, CPF/CNPJ, contato, endereço
- **Histórico de apólices** — Todas as apólices vinculadas ao cliente
- **Propostas** — Propostas em andamento ou encerradas
- **Documentos** — Arquivos anexados ao cadastro
- **Interações** — Registro de contatos e anotações

---

## Como visualizar o histórico de apólices de um cliente

1. Abra o cadastro do cliente
2. Clique na aba **"Apólices"**
3. Você verá todas as apólices com status, vigência e produto
4. Clique em uma apólice para ver os detalhes completos

---

## Como anexar documentos ao cadastro

1. Abra o cadastro do cliente
2. Clique na aba **"Documentos"**
3. Clique em **"Anexar documento"**
4. Selecione o arquivo (formatos aceitos: PDF, JPG, PNG)
5. Clique em **Enviar**

---

## O que fazer se o CPF/CNPJ já está cadastrado

O sistema não permite duplicatas de CPF/CNPJ. Se você tentar cadastrar um cliente com documento já existente, verá uma mensagem de erro.

**O que fazer:**
1. Use a busca para localizar o cliente já existente
2. Se os dados estiverem desatualizados, edite o cadastro existente
3. Se for um cadastro incorreto, entre em contato com o Admin para avaliação

---

## Perguntas frequentes

**Posso excluir um cliente?**
Clientes com propostas ou apólices vinculadas não podem ser excluídos. É possível arquivá-los para removê-los da listagem ativa.

**Como faço uma anotação sobre um cliente?**
Na aba "Interações" do cadastro do cliente, você pode registrar observações e histórico de contatos.

**Posso importar uma lista de clientes?**
Consulte o Admin — a importação em massa pode estar disponível conforme o plano contratado.
