# Aula 2.2 — Cotações

## Objetivo
Entender como criar, comparar e gerenciar cotações de seguros dentro da plataforma.

---

## O que é uma cotação?

Uma cotação é uma simulação de preço para um produto de seguro. Ela ainda não é um compromisso — serve para o cliente comparar opções antes de decidir.

> Cotação ≠ Proposta. A proposta é gerada depois que o cliente escolhe uma cotação. (veja Aula 2.3)

---

## Como criar uma cotação do zero

1. No menu lateral, clique em **Cotações**
2. Clique em **"Nova Cotação"**
3. Selecione o cliente (existente ou crie um novo)
4. Escolha o **tipo de seguro** (ex: Auto, Vida, Residencial)
5. Preencha as informações do bem/pessoa a ser segurado
6. Clique em **"Calcular"**
7. O sistema retornará as opções disponíveis com coberturas e preços

---

## Como comparar produtos e coberturas

Após calcular, o sistema exibe as opções em formato de tabela comparativa:

- Cada coluna representa um produto/plano diferente
- As linhas mostram: coberturas incluídas, franquias, limites e preço
- Use os filtros no topo para ordenar por preço ou cobertura

**Dica:** Clique em **"Ver detalhes"** em qualquer produto para ver a descrição completa das coberturas.

---

## Por que uma cotação pode não retornar resultados?

Algumas situações impedem que produtos sejam exibidos:

| Motivo | O que fazer |
|---|---|
| Nenhum produto cadastrado para o ramo | Contate o Admin para verificar o catálogo de produtos |
| Perfil do cliente fora dos critérios de aceitação | Verifique as regras do produto com o Admin |
| Produto inativo | O Admin precisa ativar o produto |
| Dados insuficientes para cálculo | Revise os campos preenchidos e complete as informações |

---

## Como salvar e retomar uma cotação

- As cotações são salvas automaticamente enquanto você preenche
- Para retomar uma cotação em andamento: acesse **Cotações** → filtre por **"Em andamento"** → clique na cotação

---

## Diferença entre cotação e proposta

| Cotação | Proposta |
|---|---|
| Simulação de preço | Documento formal para a seguradora |
| Sem compromisso | Inicia o processo de análise |
| Pode ter várias opções | Uma opção selecionada |
| Não aparece para a seguradora | Enviada para análise e aprovação |

---

## Perguntas frequentes

**Posso fazer mais de uma cotação para o mesmo cliente?**
Sim, não há limite de cotações por cliente.

**A cotação tem prazo de validade?**
Sim, os preços calculados podem ter validade limitada conforme as regras do produto. O sistema indicará se a cotação estiver expirada.

**Posso compartilhar a cotação com o cliente?**
Sim, use o botão **"Compartilhar"** para enviar um link ou PDF com as opções ao cliente.
